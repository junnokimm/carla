# M1·M2 NoA 자동 진출 (2026-10-19)

> 아래는 이전 구현 기록이다. 2026-10-20에 운전자 확인 없는 자동 진출 시작을
> 제거하고 [진출 안내 중 깜빡이 확인 방식](signal_confirmed_module_exit.md)으로
> 변경했다. 현재 설정과 테스트 기준은 새 문서를 따른다.

`run_pilot.cmd`에서 구성하는 M1·M2 진출은 확인 키나 깜빡이 입력 없이 시작한다.
훈련은 기존 깜빡이 확인 방식을 유지한다. M2 배정 및 NoA 활성화·해제 조건은 변경하지 않는다.

## 동작

- 기존 출구·모듈 시간 창 안에서 실제 NoA 활성 상태를 확인한다. Manual이면 자동 명령을 보내지 않는다.
- 운전자 입력을 먼저 처리한다. 일반 깜빡이 차로변경이 있거나 진행 중이면 자동 요청을 중복 제출하지 않는다.
- 같은 방향·같은 도로의 안쪽 차로에서는 기존 인접 차로 검사와 실행기를 통해 한 차로씩 우측으로 이동한다. 관측된 차로변경 완료 전에는 다음 요청을 보내지 않는다.
- 마지막 진출 차로에 도달한 뒤 **최종 출구 접근 도로에서만** Traffic Manager에 단일 Right 분기를 지정한다. 끝차로 진입만으로 직진/진출이 무작위 선택되는 것을 방지한다.
- NoA가 해제되거나 진출 경로가 지정된 상태에서 운전자가 깜빡이 차로변경을 요청하면 자동 진출 경로를 취소한다. NoA를 임의로 다시 켜지 않는다.
- 방향지시등은 시스템 요청 시 켜고, 기존 차로변경 완료 처리로 끈다. 핸들·페달 축, 입력 감도, NoA 해제 임계값, 위험사건은 변경하지 않았다.

## 실패 및 기록

자동 진출은 `lc_decision.decision=AUTO`, `decision_source=SYSTEM`,
`exit_policy=AUTOMATIC_NOA`로 기록한다. 차로변경 요청의 `context`는 `AUTO_EXIT`이며,
일반 깜빡이는 `GENERAL`이다. 자동 결정을 운전자 확인 입력으로 기록하지 않는다.
기존 `EXIT_CONFIRMED` 결과명은 관측된 실제 진출 완료를 뜻하며, 운전자의 확인 여부는 `decision`으로 구분한다.

`lc_auto_step_requested`, `lc_auto_exit_lane_reached`, `lc_auto_route_submitted`,
`lc_auto_route_cancelled`로 실행 단계를 추적한다. 실제 경로 관측이 있어야 `lc_completed/EXIT`를 기록한다.

접근 시간 창 종료, 경로 이탈, 인접 차로 요청 거절, 방향지시등 읽기 실패 및 제출 오류는 진출 실패/중단 사유를 남긴다.
이 실패를 세션 종료나 강제 수동 전환으로 처리하지 않는다. 새 이벤트의 로그 전달 오류는 제한된 오류 목록에 남기고 제어를 계속한다.
이미 네이티브에 전달된 차로변경의 완료가 불확실하면 임의로 완료 처리하거나 두 번째 명령을 보내지 않는다.
실제 시뮬레이터·장치 장애에 대한 기존 관리자 안내·복구 절차는 유지한다.

## 검증과 제한

- 물리 장치/시뮬레이터 접속을 금지한 오프라인 회귀 검사: `data/auto_exit_verification/`.
- 실제 Town04 OpenDRIVE 및 생산 네이티브 LocalizationStage 검사: `data/noa_tm_build/patched_test.txt`.
- 네이티브 빌드 및 기존 RPC 수신 보호 검사: `data/noa_tm_build/auto_exit_build.log`.
- 기존 소프트웨어 환경을 덮어쓰지 않고 프로젝트 전용 CARLA 클라이언트를 재빌드했다. 해시 검증 및 RPC 예외 보호는 유지한다.

오프라인 검사에는 실제 차량 동역학·교통량·장치 입력 타이밍의 실주행 검증이 포함되지 않는다.
현장에서는 M1/M2 NoA 자동 진출, Manual 직접 진출, 좌우 깜빡이 차로변경과 자동 소등,
진출 중 NoA 해제, 모듈 종료 후 로그/ZIP 저장을 확인해야 한다.

최종 결과: 전체 2,447건 통과, 2건 건너뜀, 기존 화면 배치 기대값 실패 5건.
실패 목록은 `data/time_alignment_verification/baseline_existing_failures.txt`의 수정 전 목록과 같다.
이번 자동 진출 검사 43건은 모두 통과했다. 네이티브 32건의 기존 차로변경 검사와 4건의 출구 선택/취소 검사,
기존 RPC 보호의 비정상 연결 72건 거절 및 정상 연결 유지 검사도 통과했다.
최종 전체 결과는 `data/auto_exit_verification/full_unrestricted.txt`와 `.xml`에 저장되어 있다.
