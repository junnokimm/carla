M2 시작 전 아이트래커 영역 확인

실행
  cd C:\dev\carla
  .\run_pilot.cmd

M1 -> 휴식 -> M2 안내에서 Space -> 시선 확인 -> 진행자 확인 -> M2 주행.
검사 시간은 M2의 780초 주행 시간에 포함하지 않는다.
--no-gaze를 명시한 실행은 이 시선 검사도 생략한다.

개인 보정과 영역 확인은 다른 절차다.
- 개인 보정은 새 피험자마다 M1 전에 Eye Tracker Manager에서 수행한다.
- 기존 M1 전 외부 보정 안내는 유지한다. 보정 성공을 SDK로 자동 확인하는 기능은 아니다.
- M2 직전 추가한 단계는 고정된 매핑을 이용한 짧은 독립 영역 확인이다.
- 이 단계가 보정값이나 태블릿 매핑을 자동으로 맞추거나 갱신하지 않는다.
- 재보정은 결과 화면에서 Alt+Tab으로 Eye Tracker Manager를 이용하고 돌아와 R로 재검사한다.
  결과 화면에서는 검사 수집기를 종료하므로 보정과 검사 스트림을 의도적으로 동시에 실행하지 않는다.

검사 방법
- 실제 주행 모니터의 전체화면에서 진행한다. F11 -> 창 이동 -> F11로 모니터를 선택할 수 있다.
- Space로 개인 보정 완료 및 표시 화면을 확인하고 검사를 시작한다.
- 전방 중앙 -> 좌측 미러 중앙 -> 우측 미러 중앙 -> 실제 태블릿 과제 표시 영역 중앙 -> 전방 중앙.
- 각 대상을 먼저 바라본 뒤 진행자가 Space. 1초 준비 후 5초를 기록한다.
- 최소 측정/준비 시간은 총 30초이며, 연결·안내·진행자 입력 시간은 별도다.
- 태블릿 네 모서리는 합격 대상으로 사용하지 않는다. 중앙 확인을 태블릿 전체 검증으로 해석하지 않는다.
- 측정 중 창 포커스나 화면 모드를 바꾸면 그 시도는 미충족으로 남긴다.
- ESC/검사 창 닫기는 M2 안내로 돌아간다. 검사 실패가 실험을 자동 종료시키지는 않는다.

잠정 운영 기준 (Tobii 공식 합격선이나 연구 타당성 인증이 아님)
  규칙 버전: m2-coarse-aoi-v1-provisional
  영역마다 모두 만족해야 합격:
  - 콜백 수 >= Nano 60Hz 기준 기대 수의 90% (5초에 270개 이상)
  - 한쪽 이상 유효한 눈 좌표 >= 수신한 전체 샘플의 85%
  - 지시한 영역으로 분류 >= 수신한 전체 샘플의 80%
  - 다른 명명된 영역으로 오분류 <= 수신한 전체 샘플의 5%
  - 연속 추적/콜백/표시 매핑 공백 <= 0.5초
  - 시각·시퀀스 역행/중복 없음
  원본 무효 샘플도 분모에 포함하며, 콜백 누락은 별도 검사한다.
  단안 데이터도 허용하지만 기존 원본과 시간 기록에서 단안/양안을 구분한다.
  전방은 처음과 마지막 모두 만족해야 한다.
  다른 영역으로 5% 넘게 잘못 분류되면 잘못 지목된 영역도 제외한다.
  반복 피험자 파일럿을 바탕으로 기준을 확정하고 본실험에서는 기준 버전을 고정해야 한다.

불합격 처리
- R: 전체 영역 재검사. 최초 1회 + 재시도 2회, 총 3회까지.
- 자세 또는 개인 보정이 바뀌면 전체 영역을 다시 확인한다.
- 모든 시도 원본·판정·오류를 보관하며, 예전 시도 중 최고 점수를 골라 합격시키지 않는다.
- 최종 시도의 영역별 결과를 사용한다.
- 합격: Space로 M2 시작.
- 미충족: F8 -> 제외 영역 안내 -> Enter로 진행자가 명시적으로 계속 진행.
- 검사 연결/SDK/화면 오류도 합격으로 간주하지 않고 제외 여부 확인을 받는다.
- 제외는 시선 지표에만 적용한다. 주행·핸들·NoA·위험사건 동작을 바꾸지 않는다.
- 검사 저장에 실패해도 메모리의 제외 결정은 M2 시선 수집기로 전달한다.

저장 위치: data/p8_operator/<Run ID>/
  gaze_precheck/M2-<시도>-<ID>/check_summary.json
    영역별 비율, 기준 버전, 실패 이유, 사용한 태블릿 프로필 해시.
  gaze_precheck/M2-<시도>-<ID>/gaze/<수집 ID>/
    SDK 원본, 실제 실험과 같은 분류기의 결과, 창/표시 영역, 매핑 사본, 시간 기록.
  m2_gaze_quality.json
    최종 진행자 결정, 분석 포함/제외 영역, 피험자·실행 ID.
  gaze/MODULE_2_RUNNING-<ID>/summary.json
    gaze_precheck와 analysis_seconds_by_aoi.
  gaze/MODULE_2_RUNNING-<ID>/gaze.jsonl 및 intervals.jsonl
    analysis_aoi_included: true/false/null. 원본 분류와 시간은 보존.
  gaze_totals.json
    m2_analysis_seconds_by_aoi: 불합격/미검증 영역은 null. 0초로 바꾸지 않는다.
    기존 tablet_classified_seconds는 원본 관측 합계이므로 제외 판정 전후 비교용이며,
    검증을 통과한 M2 지표로 해석하지 않는다.

시선 누락은 '태블릿을 안 봄'이 아니다. 전체 실제 태블릿 주시시간은 여전히 확정할 수 없다.
M2 직전 확인은 실제 주행 내내 정확했다는 보증이 아니며, 주행 중 손실/오류도 함께 검토한다.
M1/훈련의 기존 원본·시간은 보존하고 M2 확인 결과로 소급해 합격시키지 않는다.
완료된 검사 기록과 결정 파일은 기존 결과 ZIP에 함께 포함된다.
