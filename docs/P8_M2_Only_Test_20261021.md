# M2 단독 테스트

2026-10-21. 훈련·M1·휴식을 실행하지 않고 새 M2 테스트를 시작하는 진입점을 추가했다.
기존 `run_pilot.cmd` 통합 실행의 기본 흐름은 그대로다.

## 실행

다른 실험을 종료한 뒤 Unreal에서 Town04를 Play 상태로 두고 PowerShell에서 실행한다.

```powershell
cd C:\dev\carla
.\run_m2_test.cmd
```

참가자 번호(예: `001`) → M2 배정(`1=MANUAL`, `2=NoA`)을 입력한다.
저장 유형은 `test`로 고정하며 M1 배정을 묻지 않는다.

흐름: 경고음 안내(SPACE) → M2 안내(SPACE) → 기존 M2 시선 확인 → M2 주행 → 결과 저장.
시선 검사 재시도·불합격 영역 제외 후 진행·검사 취소의 기존 동작을 유지한다.
핸들·페달 준비도 M2 실제 주행을 시작할 때 기존 절차대로 수행한다.

배정을 미리 지정할 수도 있다.

```powershell
.\run_m2_test.cmd --participant-id 001 --m2 1
.\run_m2_test.cmd --participant-id 001 --m2 2
```

`run_pilot.cmd --m2-only`도 동일한 진입점이다. 시선 수집이 필요 없는 장비 테스트는
`--no-gaze`를 추가한다. M2 단독 실행에는 `--m1` 또는 `--session-type pilot`을 사용할 수 없다.

## M2 동작과 저장

- 기본 780초 및 최근 추가한 위험사건 대기 시간 연장을 그대로 사용한다.
- M2의 진출 선행 조건·예정 시각(400~600초 추첨)·현재 속도 기준 4초 거리·정지/극저속/교차로 보류를 유지한다.
- 깜빡이 진출·NoA 차로변경·NoA 해제·핸들·페달·장애물 충돌 후 SPACE 종료 동작을 유지한다.
- 기존 supervisor를 거쳐 실행하므로 콘솔 진단·비정상 종료 후 부분 기록 복구·ZIP 내보내기를 유지한다.
- 원자료: `C:\dev\carla\data\p8_operator\001_test`.
- ZIP: `C:\dev\carla\data\p8_operator\_exports\001_test.zip`.
- 같은 번호를 재사용하면 기존 파일을 덮어쓰지 않고 `001_test_02`처럼 새 이름을 예약한다.

`session_manifest.json`과 `collection/collection_status.json`에 `execution_scope=M2_ONLY_TEST`를 기록한다.
미실시 단계는 manifest의 `not_performed_stages`에 남기며, 훈련·M1의 실행 기록이나 완료 기록을 만들지 않는다.
호환용 study_context의 M1 조건 필드는 보존하지만 `m1_assignment_applied=false`로 명시하고,
SuRT 보고서는 `NOT_APPLICABLE_M1_NOT_PERFORMED` / `m1_condition=null`로 남긴다.
경고음 안내 기록은 `m2_test_warning_audio_*`로 구분한다.
